# Spanish Sprint 🇪🇸

A lightweight Spanish learning web app built with vanilla HTML, CSS and JavaScript.

## Features

- Mini Spanish lessons
- Flashcards with 8 high-frequency words
- Quick multiple-choice quiz
- XP, levels, streaks and accuracy
- Progress saved locally with `localStorage`
- Responsive mobile layout
- GitHub Pages deployment workflow

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish on GitHub Pages

Push these files to `main`. In **Settings → Pages**, choose **GitHub Actions** as the source. The included workflow deploys the site automatically on pushes to `main`.
