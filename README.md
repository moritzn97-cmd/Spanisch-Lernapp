# Español – Spanisch lernen 🇪🇸

Mobile Spanish learning PWA for iPhone.

## Features
- A1 vocabulary training
- Multiple-choice answers
- XP
- Learned-word review
- Local browser storage
- iPhone-friendly responsive layout

## GitHub Pages
Enable **GitHub Actions** under **Settings → Pages** as the source. The site is then deployed by the workflow in `.github/workflows/pages.yml`.
